# Security policy

AltQueue is an MVP and has not had an independent security review. Do not expose it publicly without TLS and `ALTQUEUE_TOKEN` (see [docs/RUNNING.md](docs/RUNNING.md)).

To report a vulnerability, please use GitHub's private
[security advisory](https://github.com/tusharsinghbisht/altqueue/security/advisories/new) form rather than a public issue.
